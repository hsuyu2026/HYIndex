# HY INDEX（HY綜合指數）

以台灣證券交易所加權股價指數為設計靈感、以 **100.00** 作為基期的個人生活狀態追蹤與分析系統。採用股票行情看盤介面設計（紅漲、綠跌、灰持平），所有資料預設儲存於瀏覽器本機 IndexedDB，無須帳號登入，亦不串接任何付費或 AI API。

---

## 核心特色

1. **獨立計算引擎 (`src/engine/calculations.ts`)** — 系統版本 `v1.1.3`（每日偏離基準分數累積制 ＋ K 線圖彙整與趨勢預測）
   - **固定參數集中管理**：`INITIAL_HY_INDEX = 100`、`BASELINE_SCORE = 50`、`ACCUMULATION_FACTOR = 1`、`FOUR_INDEX_WEIGHT = 0.8`、`HABIT_INDEX_WEIGHT = 0.2`。
   - **四大狀態指數（佔 80%）**：現狀與未來目標滿意度 (30%)、自我狀態表現 (25%)、心情指數 (25%)、精力值 (20%)。支援部分欄位選填並自動依權重正規化；`0` 分視為有效數值，未填寫欄位絕不當作 0 分。
   - **習慣紀錄（佔 20%）**：每日每項限計一次（正面：正常作息 +2、閱讀 +3、好好休息 +2；負面：晚睡 -2、3C 使用過量 -2、拖延 -2、縱慾 -1、遲到 -1），依 `H = min(100, max(0, 50 + 10 × Hp))` 換算。
   - **每日偏離累積制**：每日綜合分數 `S_t = 0.8 × S + 0.2 × H`，每日偏離分數 `D_t = S_t - 50`，累計指數 `HY_t = HY_{t-1} + D_t × 1`，並同步顯示相對於前有效交易日 HY 的漲跌百分比。一天的結束時間為隔日凌晨 03:00（`00:00–02:59` 紀錄歸屬前一日）；無紀錄日與休市日不產生偏離分數，維持前一個有效交易日數值（以灰色標示並保持折線連續）。
2. **圖表系統（日線與週／月／年 K 線圖）**
   - **日線走勢圖**：支援預設「最近 7 天」、14 天、30 天、全部及自訂日期區間選擇，並支援上一區間／下一區間／最新區間導覽與縮放平移。
   - **週 K／月 K／年 K 線圖**：嚴格以每日正式 HY 指數紀錄為唯一資料來源，依自然週（週一至週日）、自然月（`YYYY-MM`）與自然年（`YYYY`）彙整開盤（`O_p`）、最高（`H_p`）、最低（`L_p`）、收盤（`C_p`）、區間變化與變化率參考（`R_p`）；進行中區間標註「未完成」，休市日與無紀錄日不產生虛構 K 線。
3. **每週正式結算與延遲補結算**
   - 依 `Asia/Taipei` 時區週一 03:00 至隔週一 02:59 自動執行延遲結算，結算時間為每週一凌晨 03:00；**每週結算不重設 HY 指數**，並記錄期初 HY、期末 HY、本週累積偏離（`W_t`）、最高／最低 HY、參與紀錄 ID 與系統版本以便追溯。
   - 修改或刪除已結算週期的歷史紀錄後，自動從初始基期 100 重新計算受影響的後續交易日與週報。
3. **休市與開市管理**
   - 手動休市期間指數凍結於最後有效開市指數，休市紀錄保留於歷史但絕不納入指數或週結算計算；支援跨週休市。
4. **實際影響力分析、趨勢預測與 AI 提示詞產生器**
   - 區分固定權重與實際貢獻度（`Ci`、`Pi`），僅針對兩週皆有有效資料的共同項目進行比較。
   - **趨勢預測頁**：每次進入前必先顯示「僅供參考」警示，並依據過去 30 天平均每日偏離分數以虛線模擬未來 7 天潛在走勢，同步從四大指數、習慣紀錄、正負情緒標籤與歷史文字紀錄拆解成因（正負習慣最高次數與正向／負向情緒分別以紅／綠色標示）。
   - 內建週報 AI 分析提示詞產生器，支援預覽與一鍵複製，方便貼上至外部 AI 工具進行分析。
5. **本機資料備份與還原**
   - 支援完整 JSON 備份匯出與還原（匯入覆蓋前自動下載現有資料備份並檢查完整性）。
   - 支援 UTF-8 BOM CSV 數值明細匯出（可直接以 Microsoft Excel 開啟）。

## 目錄結構

```text
src/
├── components/
│   ├── AppShell.tsx        # 頂部行情狀態列（台北時間、交易/休市狀態）與七頁導覽
│   ├── HyChart.tsx         # Chart.js 走勢與 K 線圖（日線預設 7 天 / 週月年 K 線、縮放平移與區間檢視）
│   ├── IndexDisplay.tsx    # 台股紅漲綠跌數值顯示元件
│   └── OnboardingFlow.tsx  # 首次使用四步驟基準設定流程
├── context/
│   └── HyContext.tsx       # 全域狀態管理與每週結算自動對帳
├── engine/
│   └── calculations.ts     # 集中管理所有指數、權重、影響力與週報提示詞計算公式
├── pages/
│   ├── DashboardPage.tsx   # 行情總覽
│   ├── DailyRecordPage.tsx # 新增／編輯每日紀錄
│   ├── HistoryPage.tsx     # 歷史紀錄搜尋與篩選
│   ├── StatisticsPage.tsx  # 固定權重與實際影響力統計
│   ├── ForecastPage.tsx    # 30 日平均偏離推估未來 7 天潛在走勢與歷史成因解析
│   ├── WeeklyReportPage.tsx# 每週正式結算報告與 AI 提示詞預覽複製
│   ├── MarketControlPage.tsx# 休市與開市管理
│   └── DataSettingsPage.tsx# JSON 備份匯入/匯出、CSV 匯出與系統設定
├── storage/
│   ├── db.ts               # IndexedDB 資料表與交易存取
│   └── localPrefs.ts       # localStorage 輕量介面偏好設定
├── types/
│   └── hy.ts               # TypeScript 型別與權重/習慣定義
└── utils/
    └── taipeiTime.ts       # Asia/Taipei (UTC+8) 日期與週期邊界工具
```

## 安裝與啟動說明

### 1. 環境需求
- Node.js 18 或以上版本
- npm 9 或以上版本

### 2. 安裝相依套件
```bash
npm install
```

### 3. 啟動開發伺服器
```bash
npm run dev
```
啟動後請於瀏覽器開啟 `http://localhost:3000`。

### 4. 型別檢查與正式建置
```bash
npm run lint
npm run build
```
建置輸出檔案位於 `dist/` 目錄。
